# Ping Pong

Ретро-понг на Python 3.12+ и Pyxel. Сейчас реализованы главное меню и заглушка игрового поля.

```sh
uv sync --locked
uv run pong
```

Внутреннее разрешение — 300×400, масштаб — ×2 (600×800). На macOS изменение размера и кнопка увеличения окна отключены через небольшой адаптер Cocoa: публичный API Pyxel не предоставляет этого параметра. На других ОС запрет изменения размера пока не реализован. Размер указан для содержимого окна, без системного заголовка.

## Управление

- Мышь: нажать на сложность, число игроков или START.
- ↑/↓: перейти между пунктами; сложность выбирается сразу.
- ←/→: выбрать число игроков, когда фокус в разделе Players.
- Tab: перейти к следующему пункту.
- Enter или пробел: подтвердить пункт / нажать START.
- Esc на игровом поле: вернуться в меню с сохранением выбора.
- Закрытие окна: системная кнопка закрытия.

Medium и 1 player выбраны при запуске. START показывает поле без игровой физики.

Музыка и эффекты созданы программно в `src/pong/audio.py`: оригинальная 16-секундная петля, три музыкальных канала и отдельный канал для реакций меню. Внешние шрифты и ресурсы не требуются — используется масштабированный пиксельный шрифт Pyxel.
